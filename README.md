# HỆ THỐNG QUẢN LÝ SÁCH

## Giới thiệu

Ứng dụng quản lý sách được xây dựng
và triển khai trên nền tảng điện toán đám mây.

## Công nghệ sử dụng

- Frontend: React
- Backend: Node.js, Express
- Database: MongoDB Atlas
- Version Control: Git, GitHub
- Container: Docker
- Deployment: Render

## Chức năng

- Xem danh sách sách
- Xem chi tiết sách
- Thêm sách
- Cập nhật sách
- Xóa sách
- Tìm kiếm sách

## Cấu trúc dự án

- frontend: Giao diện React
- backend: REST API Node.js

## Hướng dẫn chạy

Hướng dẫn cài đặt và chạy frontend/backend
sẽ được bổ sung sau khi hoàn thành ứng dụng.
